# Changelog

## 1.0.0 — 2026-11-15

- Windows desktop with Generate, Inspect, Verify, and Developer Guide screens.
- SHE M1–M5 generation, AES-128 random key creation, five/six flag profiles,
  and explicit bank selection.
- Authenticated message inspection and received-proof verification.
- Portable C headers, JSON, and text exports; standalone file-based CLI.
- Source tests, standalone Windows builds, checksums, and GitHub release workflow.
- User, protocol, CLI, development, publishing, and key-handling documentation.
